# 나만의 우주공방

기획서의 공방을 내려다보기 시점으로 구현한 Python + pico2d 프로젝트입니다.
작업복·고글 차림의 주인공으로 공방을 이동하고 시설별 안내 화면을 이용할 수 있습니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python main.py
```

Windows의 맑은 고딕을 자동으로 사용합니다. 다른 환경에서는 한국어 TTF 폰트의 경로를
`SPACE_WORKSHOP_FONT` 환경 변수로 지정할 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 상하좌우 이동, 두 방향을 함께 누르면 대각선 이동 |
| E / Enter | 가까운 시설 이용, 열린 화면 닫기 |
| ↑ / ↓ 또는 W / S | 시설 화면의 항목 선택 |
| ← / → | 재료 구매 수량 변경 |
| Space | 재료 구매, 작업대 제작 시작·완성품 회수 |
| 마우스 왼쪽 버튼 | 항목 선택, 돌아가기 |
| Esc | 시설 화면 닫기, 공방 화면에서 종료 |

작업대에서 초급 장비 제작·회수, 재료 보관대에서 재료 구매, 주문 게시판에서 고객과 보상,
장비 진열대에서 장비별 보유 수량, 강화 장치에서 최상급 장비와 성장 재료를 확인할 수 있습니다.
초기 자금은 100코인이며, 현재 코인은 화면 우상단에 표시됩니다.
재료 보관대에서 재활용 부품 8코인, 고급 복합소재 12코인, 전자회로 4코인에 구매합니다.
단가·보유량·수량을 확인하고 구매 버튼 또는 Space를 누르면 코인과 보유량이 갱신됩니다.

## 초급 장비 제작

| 장비 | 재활용 부품 | 전자회로 | 제작 시간 |
| --- | --- | --- | --- |
| 고철 드릴 | 2개 | 1개 | 10초 |
| 보급형 우주복 | 3개 | 2개 | 12초 |
| 소형 산소통 | 2개 | 2개 | 10초 |

초급 장비를 하나씩 제작하는 재료비는 총 76코인입니다.
작업대에서 제작 버튼 또는 Space를 누르면 재료를 소모하고 제작을 시작합니다.
작업대는 한 번에 장비 하나를 제작합니다. 메뉴를 닫고 공방을 이동해도 제작 시간은 흐릅니다.
화면 상단의 진행 상태가 완성으로 바뀌면 작업대에서 회수 버튼 또는 Space를 누릅니다.
완성품을 회수하면 장비 보유량에 추가되고 다음 장비를 제작할 수 있습니다.
장비 진열대의 목록에는 종류별 개수, 상세 화면에는 선택한 장비의 보유 수량이 표시됩니다.
제작 중이거나 완성 후 작업대에 남아 있는 장비는 회수할 때 보유 수량에 반영됩니다.
진열대 우상단에서는 회수한 장비의 총개수를 확인할 수 있습니다.

## 파일

- `main.py` — pico2d 실행, 입력 처리, 화면과 시설 메뉴 표시
- `player.py` — 이동 속도, 발 위치 충돌, 방향별 걷기 애니메이션
- `workshop.py` — 공방의 이동 영역, 시설 배치와 안내 내용
- `game_state.py` — 코인·재료·장비 보유량, 재료 구매, 제작 타이머와 회수 처리
- `asset/bg_workshop_room.png` — 내려다보기 공방 배경, 1280×720
- `asset/player_walk.png` — 4방향 주인공 스프라이트 시트, 256×384
- `documents/` — 기획서와 발표 자료

주인공 시트는 위에서부터 아래·왼쪽·오른쪽·위 방향이며, 각 행에 64×96 크기의
대기·걷기·중간·걷기 프레임 4개가 있습니다. 이동 속도는 초당 190픽셀이며 대각선도
같은 속도로 이동합니다. 발 아래의 충돌 영역을 기준으로 벽과 가구를 통과하지 못합니다.

배경과 주인공은 ImageGen 내장 도구로 제작했습니다. 배경에는 기존 에셋의 색감과
공방 구성을 참조해 열린 바닥 공간을 가진 내려다보기 시점을 요청했습니다.
주인공에는 초보 작업자 초상화의 작업복·고글 외형과 투명 배경의 4방향 걷기 시트를 요청했습니다.
